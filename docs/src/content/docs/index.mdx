## 內容簡介

《石冢：陽春版》是一款關於穿越地底通道、頹圮城堡、幽暗森林與各種恐怖之地的冒險遊戲。角色創建完全隨機且快速，探索充滿張力與回報，戰鬥則混亂而致命。
