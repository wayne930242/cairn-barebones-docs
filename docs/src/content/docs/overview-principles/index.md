## 總覽

### 中立

守護人（Warden）的職責，是扮演中立的仲裁者，清楚呈現規則、情境、非玩家角色（NPC）與敘事。

### 無職業限制

角色的定位或技能不受單一職業限制。相反地，角色攜帶的裝備與累積的經歷，才會定義其專長。

### 死亡

角色可能很強大，但同樣容易受到各種形式的傷害。死亡總在轉角處，但從不隨機，也絕不會毫無徵兆。

### 虛構世界優先

骰子不一定能反映障礙的難度或結果。相反地，成敗取決於遊戲世界中的要素，並由守護人與玩家透過對話仲裁。

### 成長

角色會透過遊戲世界中的進展而改變；他們藉由在危險事件中存活、克服障礙，獲得新的技能與能力。

### 玩家選擇

玩家應該始終理解自己做出選擇的理由；關於潛在風險的資訊，也應自由且頻繁地提供。

### 原則

守護人與玩家各自都有一些準則，協助營造特定的遊戲體驗：重視批判性思考、探索，以及自然生成的敘事。

### 共同目標

玩家彼此信任，一同投入共享的環境、角色目標與隊伍挑戰。因此，隊伍通常會像團隊一樣，為了共同目標而合作。

## 玩家原則

### 自主性

- 屬性（Attribute）與相關豁免（Save）並不能定義你的角色。它們只是工具。
- 不要只問「你的角色會怎麼做」；也要問「你會怎麼做」。
- 運用你的直覺、物品與人脈，發揮創意。

### 團隊合作

- 在一頭衝出去之前，先尋求其他玩家的共識。
- 對目標與界線保持共識，互相尊重；團體合作能比單打獨鬥完成更多事情。

### 探索

- 提問並仔細聆聽細節，比你擁有的任何數值、物品或技能都更有用。
- 坦然接受守護人的描述，不必猜疑，但也不要畏於尋求更多資訊。
- 前進的道路從來不只有一條正解。

### 交談

- 把非玩家角色當成真實的人，依靠你的好奇心安全地取得資訊、解決問題。
- 你會發現，多數人都很有趣；在訴諸暴力之前，他們通常會想先把事情談清楚。

### 謹慎

- 戰鬥是一種選擇，而且很少是明智的選擇；想想暴力是否真的是達成目標的最佳方式。
- 設法讓局勢對你有利；情勢不利時就撤退。

### 規劃

- 透過偵察、低調行事與蒐集事實，思考避開障礙的方法。
- 做些調查，四處打聽你的目標。

### 野心

- 設定目標，運用手上微薄的資源，一步步向前。
- 什麼都別指望。靠自己贏得名聲。
- 讓事情持續向前發展，玩下去看看會發生什麼事。

## 守護人原則

### 資訊

- 隨著角色探索遊戲世界，提供有用的世界資訊。
- 玩家不需要擲骰，就能了解自身處境。
- 回答他們的問題時，要有幫助且直接。
- 誠實回應、始終如一地描述，並讓他們知道自己隨時可以繼續提問。

### 難度

- 優先依據情境與現實，而不是數字與機制。
- 如果玩家想做的事確實不可能，任何擲骰都無法讓他們做到。
- 玩家描述的行動，以及他們利用情境的方式，合理嗎？如果合理，就讓它發生。
- 豁免涵蓋大量不確定的情況；對於具風險的行動，通常只需要豁免就夠了。

### 準備

- 遊戲世界是有機、可變且隨機的。它會自行理解情勢，也會突然轉向。
- 使用隨機表與生成器來發展情境，而不是故事或劇情。
- 非玩家角色會記得玩家角色（Player Character）說過與做過的事，以及他們如何影響世界。
- 非玩家角色不想死。將他們的自利與求生意志融入每個人的性格。

### 敘事焦點

遊戲中自然生成的體驗才是重點，而不是數學或角色能力。提供武器訓練師與個人任務，協助玩家提升與專精。

- 留意玩家的需求與渴望，然後把符合現實的機會放到他們面前。
- 匕首抵住你的喉嚨時，不論你的護甲（Armor）多昂貴、訓練多麼精湛，都會要了你的命。

### 危險

- 遊戲世界會為玩家角色帶來真實的疼痛與死亡風險。
- 危險存在時，要向玩家預示嚴重的危機。越危險，就要越明顯。
- 把陷阱放在明顯可見之處，讓玩家花時間想出解法。
- 給玩家解決問題、與世界互動的機會。

### 寶藏

- 寶藏與發現它的環境密切相關。它述說著一個故事。
- 寶藏極其珍貴，幾乎總是笨重不便攜帶；除了價值與聲望之外，很少有其他用途。
- 遺物（Relic）不是寶藏，但它們實用且有趣。
- 用寶藏當誘餌，引玩家前往奇異之地；那裡有令人生畏的敵人把守。

### 選擇

- 當情勢陷入停滯時，給玩家一個明確的選擇，迫使局勢產生結果。
- 當玩家的意圖模糊時，用二選一的「所以，要 A 還是 B？」來回應。
- 運用這種對話方式共同合作，讓遊戲持續前進。
- 確保玩家角色的行動能在遊戲世界留下痕跡。
